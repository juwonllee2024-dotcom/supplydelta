# Changelog

## 0.1.0 — 2026-10-09

Initial public release:

- compare npm package directories and `.tgz` artifacts;
- show lifecycle hook changes and conservative capability signals;
- report dependency/file deltas with human and JSON renderers;
- support `--fail-on install-script` and `--fail-on any-change`;
- inspect archives without running package lifecycle scripts;
- include CI, tests, security policy, and contribution guidance.
